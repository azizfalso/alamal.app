# العمل — تطبيق تتبع أرباح العمل بالساعة

تطبيق أندرويد عربي (RTL) يعمل دون إنترنت.

- **اسم الحزمة:** `com.alamal.app`
- **الحد الأدنى:** أندرويد 12L (API 32)
- **الهدف:** أندرويد 15 (API 35)
- **المعمارية:** `arm64-v8a`
- **البناء:** release موقّع من GitHub Actions

## Repository secrets المطلوبة

| الاسم | الوصف |
|---|---|
| `KEYSTORE_BASE64` | ملف keystore بصيغة Base64 (سطر واحد) |
| `KEYSTORE_PASSWORD` | كلمة مرور keystore |
| `KEY_ALIAS` | اسم المفتاح |
| `KEY_PASSWORD` | كلمة مرور المفتاح |

## البناء

يدوي فقط: **Actions** ← **Build Release APK** ← **Run workflow**.
رقم النسخة يتزايد تلقائيًا: `versionCode = رقم التشغيل`، `versionName = 1.0.<رقم>`.

## ما تم إنجازه

- الجزء الأول: الأساس، الثيم، القفل، الإعدادات.
- الجزء الثاني: المحرّك الحسابي، الرئيسية، النماذج (يوم عمل، عن بُعد، كريدي).
- الجزء الثالث (أ، ب): طبقة بيانات الدفعات + شاشة استلام الدفعة.

## قادم

- الأرشيف كواجهة.
- مشاركة الملخص.
- النسخ الاحتياطي المشفّر.
