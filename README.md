# العمل — تطبيق تتبّع أرباح العمل بالساعة

تطبيق أندرويد عربي (RTL) يعمل دون إنترنت.

- **اسم الحزمة:** `com.alamal.app`
- **الإصدار الحالي:** 2.0
- **الحد الأدنى:** أندرويد 12L (API 32)
- **الهدف:** أندرويد 15 (API 35)
- **المعمارية:** `arm64-v8a`
- **البناء:** release موقّع من GitHub Actions

## Repository secrets المطلوبة

| الاسم | الوصف |
|---|---|
| `KEYSTORE_BASE64` | ملف keystore بصيغة Base64 (سطر واحد) |
| `KEYSTORE_PASSWORD` | كلمة مرور keystore |
| `KEY_ALIAS` | اسم المفتاح |
| `KEY_PASSWORD` | كلمة مرور المفتاح |

## البناء

يدوي فقط: **Actions** ← **Build Release APK** ← **Run workflow**.
- `versionCode` = رقم تشغيل الـ workflow (يتزايد تلقائيًا)
- `versionName` = `2.0.<رقم التشغيل>`

## ما تم إنجازه

### v1.0 — الأساس الوظيفي
- الأساس، الثيم، القفل، الإعدادات.
- محرّك الحسابات، الرئيسية، النماذج (يوم عمل، عن بُعد، كريدي).
- الدفعات، الأرشيف، المشاركة، النسخ الاحتياطي.
- قفل التطبيق (30 ثانية + شاشة سوداء + Recents)، منتقي العجلة للتاريخ،
  منتقي الألوان HSV، Undo Snackbar بعد الحذف، الشريط السفلي العائم.
- بحث وتصفية في السجلات، تصدير CSV، إحصائيات متقدمة
  (متوسط الساعة/اليوم، أفضل يوم)، إشعارات WorkManager للورديات الطويلة.

### v2.0 — تحديث التصميم الدافئ
- لوحة ألوان جديدة بأسلوب Claude: بيج/كريمي مع ذهبي زيتوني.
- بطاقة علوية موحّدة: رقم كبير + 3 خلايا (مؤجل / الكريدي / الأجور).
- زر «تسجيل دخول العمل» بحدود متقطّعة — إشارة بصرية واضحة.
- زر «إلغاء الدخول» بجانب «تسجيل الخروج» عند وجود وردية مفتوحة.
- شريط إجراءات سريع ثابت فوق الشريط السفلي: يوم عمل / عن بُعد / كريدي.
- ضغط المسافات: padding البطاقات 14dp بدل 20dp، فواصل أنحف.

## قادم

- منتقي الفترة (شهر / 7 أيام / الكل) داخل الرئيسية.
- رسم بياني لساعات آخر 7 أيام.
- تحويل النماذج إلى Bottom Sheets.
- أرشيف كتقرير كامل (مشاركة كل الدفعات + عرض يومي مفصّل).
